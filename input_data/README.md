# Input data

This directory contains the input files required to run the Python scripts provided in this repository.

The observational reference is the Daily NOAA OI SST V2 High Resolution Dataset, provided by the NOAA PSL, Boulder, Colorado, USA.

CMIP6 model outputs were processed for the historical, SSP2-4.5, and SSP5-8.5 experiments.

Large raw climate datasets are not included in this repository.
